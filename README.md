# StockScout v2

StockScout is an AI-Powered Stock Research & Screening Platform for Indian Equities (NSE/BSE).

## Architecture

* **Frontend**: Next.js 16 (App Router), TailwindCSS v4, shadcn/ui
* **Backend**: FastAPI (Python) for compute-heavy tasks
* **Database**: Supabase (PostgreSQL, Auth, Edge Functions)
* **AI/LLM**: Cerebras API (ChatGPT 120B)
* **Data Sources**: Indian API (primary) & yfinance (fallback)

## Directory Structure

* `/frontend`: Next.js frontend and light API routes
* `/backend`: FastAPI Python server
* `/supabase`: Supabase migrations and configuration (to be initialized)
